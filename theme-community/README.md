# OBD Themes 独立社区

Python 3.10+，SQLite，标准库服务。无需 Agent、云 API、前端构建工具或外部账户。目录包含独立的 schema 与 themes 运行资源。可直接复制 theme-community 目录运行，或使用独立社区 ZIP。

```sh
python server.py
```

默认 http://127.0.0.1:5190 。Windows 可双击 `启动社区.cmd`。基础主题自动入库，下载量从 0 开始。

## 审核

先设置环境变量，再启动服务：

```powershell
$env:OBD_COMMUNITY_ADMIN_TOKEN = '替换成你自己的长随机密钥'
python server.py
```

页面底部“管理审核”，输入同一密钥，读取待审主题。密钥只放在本次页面内存中。未设置密钥时审核接口关闭。访客可上传 .sukitheme，须填写作者、许可并确认资源权利；全部先待审，校验不代表权利审核。

## 数据与部署

- SQLite 数据默认在 `data/community.sqlite3`；使用 `--data /absolute/path` 指定持久化目录。
- 升级代码不应覆盖 data。备份使用 `python backup.py --data data --output community-backup.sqlite3`，通过 SQLite 在线备份确保一致性。
- 默认绑定本机；容器部署可指定 `--host 0.0.0.0`，公网须使用 HTTPS 反向代理和限速，见根目录 SECURITY.md。
- `--read-only` 关闭投稿。
- 主题文件以数据库 BLOB 保存，不解压、执行或直接暴露上传路径。
- Docker 示例：`docker build -f theme-community/Dockerfile -t obd-themes .`，运行时挂载 `/data` 并用环境变量传入管理员密钥。容器默认只读，按需覆盖命令启用投稿。

## 当前边界

已支持本地账号注册/登录、作品点赞、收藏、我的作品和我的收藏；暂不含评论、邮件验证、找回密码和社交登录。其他作者的主题显示通用封面，避免接收任意 HTML/SVG；仅基础主题提供自制预览。支持的引擎当前只有 ILI9488 480×320 layout-v1。

## 主题预览与独立目录

社区自身包含 schema/theme_codec.py 和 themes/ 基础主题，不再从固件或设备工具目录加载运行依赖。首页主题详情可点击“预览主题”；本地文件选择与投稿表单也能预览。浏览器解码主题包图片、位图字体与配色，模拟 0–6500 rpm，可手动调转速、暂停爬升、播放近似开机动画；预览不计为下载、不自动上传。精确的像素布局、动画时序与性能以板上固件为准。

固件说明在 /firmware 独立页面；主题投稿不接收 .bin 固件。

## 账号与作品互动

- 用户名 3–24 位字母/数字/下划线，昵称 1–40 字，密码 10–128 字符。
- 密码使用 PBKDF2-SHA256（600000 次）和独立随机盐保存。数据库不存明文密码。
- 会话令牌使用随机值，数据库仅存令牌哈希；有效期 7 天，Cookie 为 HttpOnly、SameSite=Strict。公网 HTTPS 部署设置 `OBD_COOKIE_SECURE=1`，禁止明文 HTTP 传输账号密码。
- 登录/注册有限速，写入操作校验会话 CSRF 令牌。反向代理需另外配置限速；默认不信任客户端传入的转发 IP。
- 登录后投稿绑定当前账号昵称，客户端不能指定其他作者。历史投稿没有账号绑定，不自动认领。
- 点赞/收藏按账号和作品唯一保存，可取消；仅已发布作品可以互动。我的收藏只供当前账号查询，公开显示收藏数量，不公开收藏者清单。
- 数据库升级自动新增账号、会话、互动表及作品 owner_id，不覆盖原主题。
- 目前不提供邮箱验证、密码找回和账号删除界面；正式开放注册前需按运营需求补齐。数据库备份现在含账号凭据哈希和会话，应按敏感数据保管，不上传 GitHub。
