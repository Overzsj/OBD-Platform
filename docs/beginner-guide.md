# OBD Platform 小白使用指南

这份指南帮助你把 ESP32 仪表装起来、显示模拟数据，再连接自己的车辆。以 Windows 电脑和项目当前支持的硬件为例，不要求你先学会编程。

**普通用户不需要搭建网站。** 主题社区由运营者部署，你通过浏览器访问即可。只有用 USB 操作仪表时，才需要在自己的电脑上运行设备工具。网站账号也不等于车辆连接账号。

## 1. 先分清三个东西

| 名称 | 可以理解为 | 作用 |
|---|---|---|
| 固件 | 仪表的程序 | 连接适配器、读取车辆、解码数据、控制显示和报警 |
| 主题 | 仪表的皮肤 | 改变兼容布局中的图片、字体、颜色等画面资源 |
| 设备工具 | 电脑上的安装与设置工具 | 烧录固件、烧录主题、修改参数、备份恢复 |

更换主题通常只需要“烧录主题”，不必再刷固件。主题不会让车辆增加传感器，也不能让 ECU 返回它本来就不支持的数据。

## 2. 准备这些物品

- 一台 Windows 电脑。
- 一根能够传输数据的 USB 线。只有充电功能的线无法烧录。
- 经典 ESP32 开发板，4 MiB Flash；本项目现有硬件使用 CH340 串口。
- ILI9488 驱动、480×320 横屏的 SPI 屏幕；当前参考屏无触摸。
- 杜邦线；扩展板可选。
- 连接实车时需要兼容的 ELM327 适配器。
- 高电平触发有源蜂鸣器可选，不接也能先检查显示。

**ESP32-S3、ESP32-C3、不同 Flash 容量或其他屏幕不能直接照刷。** 外观相似并不代表兼容。不确定型号时，先拍清楚板子和屏幕标签，交给维护者或 Agent 核对。

## 3. 获取项目与设备工具

项目地址：<https://github.com/Overzsj/OBD-Platform>

先查看仓库的 Releases 是否有维护者发布的设备工具完整包。有完整包时优先下载并解压，避免自行挑选零散文件。没有 Release 时，可在仓库首页点击 **Code → Download ZIP**，解压源码包。

不要直接在压缩包里双击启动。建议解压到固定目录，例如 `D:\OBD-Platform`。

在解压目录中寻找：

```text
device-tool/
  启动工具.cmd
  app/
  固件/
    simulation/firmware-package.json
    vehicle/firmware-package.json
  主题/
    open-instrument-1.0.0.sukitheme
```

`simulation` 是桌面模拟版，`vehicle` 是实车读取版。完整固件包的 JSON 清单和它旁边的 `.bin` 必须放在一起，不要只复制 JSON。

如果源码包里没有构建好的固件，或者工具提示文件不存在，说明你还没有完整烧录包。此时先让 Agent 按项目说明编译并打包，不要随便找另一个 `.bin` 替代。

## 4. 首次运行设备工具

安装 Python 3.10 或更新的兼容版本。Windows 安装时勾选 **Add Python to PATH**，并保留 Tcl/Tk 组件。

在项目文件夹空白处右键，选择“在终端中打开”，执行：

```powershell
python -m pip install -r requirements.txt
```

安装完成后，双击 `device-tool/启动工具.cmd`。正常情况下会出现“OBD 设备工具”窗口。

如果提示找不到 Python、缺少模块或窗口一闪而过，把终端错误文字交给 Agent。不要反复重刷板子来解决电脑依赖问题。

## 5. 断电后接屏幕

以下只适用于当前参考硬件与默认固件。**先拔掉所有供电，再接线；按 GPIO 数字和信号名接，不按线的颜色接。**

| 屏幕引脚 | 连接到 ESP32 | 说明 |
|---|---|---|
| VCC | 3.3V | 当前参考接法，其他模块需核实规格 |
| GND | GND | 必须共地 |
| CS | GPIO27 | 屏幕片选 |
| RESET | GPIO17 | 屏幕复位 |
| DC / RS | GPIO16 | 数据与命令选择 |
| SDI / MOSI | GPIO23 | 屏幕数据 |
| SCK | GPIO18 | 屏幕时钟 |
| LED | 3.3V | 当前参考接法，用于背光 |

没有屏幕读取需求时，SDO/MISO 可不接。无触摸屏不接 T_CLK、T_CS 等触摸接口。

蜂鸣器如需安装：VCC 按模块规格供电、GND 共地、I/O 接 GPIO25，模块必须与当前高电平触发逻辑兼容。

扩展板的 V 排针可能由跳帽切换为 3.3V 或 5V，不能仅凭排针位置判断。GPIO 不接 5V 信号，汽车 12V 不直接接 ESP32。初次测试使用电脑 USB，车载供电另行核实。

## 6. 连接 USB，找到串口

1. 接好屏幕后，用数据线把 ESP32 连接电脑。
2. 打开 Windows“设备管理器 → 端口（COM 和 LPT）”。
3. 记下新增的端口，例如 `COM3`。你的端口不一定叫 COM3。
4. 在设备工具中选择该端口。

没有新增端口：先换一根确认能传数据的线和 USB 接口，再检查 CH340 驱动。端口忙：关闭其他串口监视器、Arduino 监视器等占用程序。

空白板可能无法“读取设备信息”，这是正常的；可以先安装完整固件。已有兼容固件的设备可以先读取信息核对。

## 7. 第一次先刷模拟版

1. 在设备工具左侧进入 **“烧录固件”**。
2. 点击 **“选择内置模拟固件”**；也可“选择固件文件…”并选择 `simulation/firmware-package.json`。
3. 核对串口和选择的模拟版。
4. 点击 **“备份并烧录固件”**。
5. 等待备份、写入和校验全部完成。过程中不要拔 USB 或关闭工具。

工具会先保存完整 4 MiB 设备备份。看到明确的完成和校验成功信息后，再观察板子。若失败，保留错误文字和备份，不要马上抹除整片 Flash。

不能自动进入下载模式时，可按住 BOOT、短按 EN/复位，在工具开始连接下载后松开 BOOT；具体以开发板和工具提示为准。

模拟版不需要接车。它用于确认屏幕、动画和声音；模拟读数不能证明你的车辆支持这些数据。

## 8. 选择并烧录主题

你可以先使用自带的 `open-instrument-1.0.0.sukitheme`，之后再更换社区主题。

使用主题社区时：

1. 打开维护者提供的正式网站地址。仓库若尚未公布地址，先使用自带主题，**不用在自己的电脑启动社区服务器**。
2. 浏览作品，打开详情，点击“预览主题”。
3. 确认屏幕和引擎兼容后下载 `.sukitheme` 文件。
4. 点赞、收藏或投稿时按网站提示注册登录；普通浏览和已发布主题下载不要求本地部署。

浏览器预览是模拟效果，实屏效果可能不同。

在设备工具中：

1. 先读取设备信息，让工具确认主题引擎和屏幕。
2. 进入 **“烧录主题”**。
3. 点击 **“选择主题文件…”**，选择下载的 `.sukitheme`。
4. 点击 **“备份并烧录主题”**，等待校验成功。

不兼容提示不能跳过。固件 `.bin` 和主题镜像不是同一种文件；新手优先使用 `.sukitheme`，不要只根据扩展名猜用途。

## 9. 设置自己的报警与显示量程

进入 **“设备参数 → 打开报警、声音和量程设置”**，先点击 **“读取当前参数”**，再修改并保存。

| 设置 | 改变什么 | 不会改变什么 |
|---|---|---|
| 报警与声音 | 何时提示、是否发声 | ECU 断油点和发动机保护逻辑 |
| 显示量程 | 灯条、竖条的显示比例 | 实际传感器读数 |

当前默认高转 5000 rpm、红线提示 6000 rpm 来自项目已有车型设置，**不是所有车辆的通用建议**。使用其他车型时按车辆资料确定阈值；不知道时先向维护者确认。

齿比未知就保持待标定，不填猜测齿比。没有触摸硬件时，不能靠改一个设置启用滑动切页。

## 10. 模拟正常后再刷实车版

显示、接线和基础声音确认正常后，回到“烧录固件”，选择 **“选择内置实车固件”**，或 `vehicle/firmware-package.json`，按同样流程备份、烧录和校验。

模拟版和实车版不能混用判断。如果离开车辆后仍然持续出现演示读数，先核对是否仍在运行模拟版。

更换固件后重新读取设备信息，核对主题与参数；同分区布局通常会保留主题和设置，分区变化可能初始化部分数据，以工具实际提示为准。

## 11. 连接 ELM327 与车辆

先把车停稳、拉好驻车，再进行调试。需要启动发动机观察读数时，在通风良好的环境中进行；驾驶过程中不操作电脑或设置仪表。

1. 将适配器接入车辆 OBD 接口，确认适配器供电。
2. 按车辆测试条件开启点火或启动发动机。
3. 给运行实车固件的仪表供电，观察连接状态。
4. 先确认转速、水温等基础数据；车速在停车时显示 0 可能正常。

经典蓝牙 SPP、BLE 和 Wi-Fi 的连接参数不同，不能混用。适配器应先核实型号、配对要求和实际协议。不要让手机上的 OBD 软件同时占用适配器连接。

当前简化设备工具主要提供烧录、报警和量程设置，**没有完整的适配器连接配置向导，也不能直接导入任意车型 JSON**。如果自动连接失败，或使用 BLE/Wi-Fi，需要维护者或 Agent 通过项目已有接口配置并验证；不要寻找指南中不存在的按钮。可提供适配器型号及不含密码的连接信息。

适配器连上不等于 ECU 数据已读通。务必检查实际读数和状态。

## 12. 看到“--”怎么办

| 现象 | 先检查什么 |
|---|---|
| 全部为 `--` | 是否为实车版、适配器连接、车辆点火状态、协议初始化 |
| 部分正常、部分 `--` | 车辆是否支持相应 PID、响应是否超时或过期 |
| 车速为 0 | 停车时可能是正常实测值；0 不等于缺数据 |
| 油温、油压、实际空燃比没有值 | 不一定经标准 OBD 提供，需要单独确认，不能用主题补齐 |

通用固件会尝试它支持的标准 OBD 数据，不代表能自动解码所有车型的私有数据。

不要为了“把数字补齐”导入未知 CAN 命令、清除故障码或执行 ECU 写入。把支持状态、原始响应或错误日志交给维护者分析。

## 13. 常见故障

| 问题 | 优先处理 |
|---|---|
| 只有背光，没有画面 | 断电检查 CS、DC、RESET、MOSI、SCK，确认屏幕驱动和固件匹配 |
| 上电一会儿反复重启 | 先换已确认稳定的 USB 电源与线，读取重启原因，区分供电与程序问题 |
| 蓝牙能配对但没有数据 | 检查 SPP/BLE 类型、服务及真实收发；配对成功不是通信成功 |
| 主题刷不进去 | 先读取设备，检查主题引擎、尺寸、完整性和独立主题分区 |
| 蜂鸣器一直响或不响 | 检查触发极性、GPIO25、共地和模块规格，先完成桌面测试 |
| 安装固件后仍显示旧主题 | 同布局更新可能保留独立主题；想换画面请单独烧录主题 |
| 找不到串口或提示被占用 | 检查数据线、驱动和其他串口程序，不要直接抹板 |

## 14. 备份和恢复

设备工具每次烧录前会在 `device-tool/备份` 保存完整设备备份。建议另存一份到自己的安全位置。

需要回退时，进入 **“备份与恢复 → 选择备份并恢复整板…”**，选择这块兼容设备的完整备份。恢复会把固件、主题和设置一并恢复到备份时的状态，操作前工具也会备份当前设备。

不要随便使用他人的整板备份；里面可能有设备设置和私人信息。不要把备份、VIN、适配器密码或真实行车记录放到公开 Issue。

## 15. 不知道怎么办，就把这段发给 Agent

推荐使用 [完整的 Agent 用户使用提示词](agent-user-prompt.md)，下方为简短求助版本。

```text
我正在使用 https://github.com/Overzsj/OBD-Platform 。
请先阅读 docs/beginner-guide.md 和当前项目代码，检查我的电脑、
ESP32、屏幕和适配器是否兼容，再帮我完成设备工具安装、备份、
模拟固件、主题和实车配置。不要在我的电脑部署主题社区服务器。
不知道的参数请先确认；没有实测的数据不要造值。
```

求助时附上硬件型号、固件版本、适配器型号、车辆年款、出错步骤和完整错误文字，能帮助维护者更快定位问题。
