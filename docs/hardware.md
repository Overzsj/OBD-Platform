# 当前硬件

经典 ESP32 双核、4 MiB Flash、CH340 USB 串口；ILI9488 3.5 寸 SPI 横屏 480×320，无触摸。

| 信号 | ESP32 GPIO |
|---|---:|
| TFT CS | 27 |
| TFT RESET | 17 |
| TFT DC | 16 |
| TFT MOSI | 23 |
| TFT SCK | 18 |
| 蜂鸣器 I/O，高电平有效 | 25 |

按现有接线，屏幕 VCC/LED 使用 3.3V，GND 共地。GPIO 不接 5V 信号。MISO 无读取需求可不接。扩展板 V 针电压需实际确认。新的供电模块、蜂鸣器和接线变更需要单独验证。

公开整理不会自动刷写已连接的板子。不要把模拟固件用于判断实车数据支持情况。
